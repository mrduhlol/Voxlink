Quick start

Three steps to your first stream

1

Start the receiver

On your Linux computer, launch the receiver or desktop app first. Find your Wi-Fi IP:

ip -brief address

Use the Wi-Fi interface address (e.g., 192.168.1.20) and port 4950.

2

Configure the phone

Open Voxlink on Android. Enter the computer's Wi-Fi IP and port 4950. Tap Start and grant microphone permission.

3

Select the mic

In Discord, OBS, or your browser, choose Voxlink Microphone as input. Speak — the level meter should move. Tap Stop when done.

Requirements

  • Both devices on the same trusted Wi-Fi (no client/AP isolation)
  • UDP port 4950 allowed through firewall on private network only
  • PipeWire + PulseAudio compat for the desktop app (pactl info should work)
  • Keep the Android app in the foreground while streaming

No encryption or authentication. Use only on trusted local networks. Never forward port 4950 to the public internet.

Features

Real-time streaming

UDP streaming with ~20ms latency on typical home Wi-Fi. Mono PCM at 48 or 44.1 kHz.

Audio controls

Mute, gain (0–200%), noise gate, sample rate selection — all on the phone.

Virtual microphone

Omarchy app creates a PipeWire source — works in any app without config.

Session stats

Elapsed time, packets sent, bytes transmitted — visible on the sender.

Saved profiles

Store up to 10 computer addresses. Restore with one tap while stopped.

Keep awake

Prevent screen sleep during streaming. Background capture not supported.

Technical details

Protocol

UDP datagrams with 12-byte header: VXL1 magic + sequence (u32 BE) + sample rate (u32 BE) + PCM16 LE mono payload.

Packet loss

Receiver reports sequence gaps. Missing packets leave silence — no reconstruction.

Android sender

Kotlin + AudioRecord. Tries 48 kHz, falls back to 44.1 kHz. Foreground service not yet implemented.

Desktop app

Tauri 2 + React + PipeWire/PulseAudio module loading. Creates temporary voxlink_mic source.

CLI receiver

Rust + socket2 + hound for WAV writing. Cross-platform, no deps on audio stack.
